# 603 Identity

Who can get into what, reviewed continuously: SSO, MFA, admin rights, and what's exposed
to the internet. Atkinson, NH.

I run identity and access security for businesses, and I publish the infrastructure code
and CI tooling I use to do it here.

- [checkov-ledger-action](https://github.com/603-Identity/checkov-ledger-action): fails the
  build whenever a Checkov scan drifts from a reviewed ledger of accepted findings, in either
  direction.
- [terraform-cloudflare-dns](https://github.com/603-Identity/terraform-cloudflare-dns): an
  OpenTofu module for managing Cloudflare DNS records, one zone at a time.
